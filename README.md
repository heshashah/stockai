# StockAI

StockAI is an AI-powered stock market analysis platform.

## Features
- Live stock market data
- IPO tracking
- Sensex & Nifty overview
- AI-based insights
- Secure authentication

## Tech Stack
- Frontend: React.js
- Backend: Node.js, Express
- Database: MySQL

## Project Structure
client/   - frontend  
server/   - backend
